# Sample Files

These files are provided for quick evaluation of ClearCounsel's provenance-removal pipeline.

| File | Description |
|------|-------------|
| `synthetic_engagement_letter.txt` | Synthetic legal engagement letter. Use this to test plain-text Unicode hygiene and AI-fingerprint removal. |

To test: upload a file via the ClearCounsel UI at http://localhost:8501, click Analyze, then Sanitize.
